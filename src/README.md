# src/
The brief's `src/` folder is represented as follows (kept in place so that every path in the programs keeps working):
- `../scripts/` analysis pipeline (features, consolidation, correlations, selector, extra graphs)
- `../suite.py` one program that builds and runs the other teams' code (also `hardware`, `stream`, `predict`)
- `../gui.py` desktop GUI
- `../implementations/` Teams 5, 6, 7 source code and the official STREAM source
